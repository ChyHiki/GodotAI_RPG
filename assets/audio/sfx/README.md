# 音效资产（程序化合成）

本目录的 wav **不是**录音素材，而是由 **`tools/gen_sfx.py`** 用纯 Python（只依赖标准库）现场合成的。
生成脚本即"源文件"—— 想改音色就改脚本里的参数重跑，不用回音频工作站。

| 文件 | 时长 | 用途 | 合成方式 |
| --- | --- | --- | --- |
| `swing_light.wav` | 0.22 s | 连击 **第 1/2 段**起手的破空声 | 带通噪声 + 时变共振峰（1.2k→3.0k Hz），快起慢落包络 |
| `swing_heavy.wav` | 0.38 s | 连击 **第 3 段**（收尾重击）的挥砍声 | 同上但更低更长（0.5k→2.0k Hz）+ 一层低频"躯体感"噪声 |
| `hit_impact.wav` | 0.20 s | **命中敌人** | 三层叠加：瞬态噪声（"啪"）+ 85→46 Hz 扫频正弦经软削波（"砰"）+ 1.3 kHz 中频填充 |

## 怎么重新生成

```bash
python tools/gen_sfx.py assets/audio/sfx
# 之后必须让 Godot 重新导入，否则引擎读的还是旧缓存：
Godot_v4.7.2-stable_win64_console.exe --headless --path . --import
```

脚本内置**质量护栏**：写盘前会算 RMS 与过零率，若"滤波器发散"（RMS 逼近峰值 + 过零率极低，
症状是输出退化成直流、听起来像一记闷雷）会直接报错退出，不让坏音频进仓库。

## 为什么程序化合成

- **可控**：三段挥砍的时间长短、亮度、低频比例都是脚本里的数字，改一个数就能重来
- **干净**：没有版权问题、没有素材库依赖、三个文件加起来 < 36 KB
- **可复用**：敌人侧的挥击/受击音用同一套函数换参数即可生成

## 谁在播它们

`scripts/player/player.gd`：
- 常量 `SFX_SWING_LIGHT` / `SFX_SWING_HEAVY` / `SFX_HIT` 指向本目录
- `_setup_audio()` 在 `_ready` 里挂两个 `AudioStreamPlayer3D`（`SfxSwing` / `SfxHit`）
- 起手（`_start_combo_step`）播破空声，命中（`_on_hit_landed`）播打击声

> ⚠️ 用 **AudioStreamPlayer3D** 而不是 2D：3D 声源会随距离衰减、按镜头方位定位
> （左后方的敌人挨打，声音就在左后）—— 这是以后做"听声辨位"的基础。
>
> ⚠️ 资源是**可缺**的：`_load_stream()` 遇到不存在的路径返回 `null`，`_play_sfx()` 静默跳过。
> 所以删掉本目录只会让游戏"没声音"，**不会报错**（也方便 clone 下来先跑起来）。
